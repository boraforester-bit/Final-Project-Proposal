# Final-Project-Proposal

# Title 
The Lull

## Repository  https://github.com/boraforester-bit/Final-Project-Proposal

## Description 
An interactive text-based horror adventure game

## Features 
- Feature 1 - Allows for an inventory that stores objects that can be used to 
interact with the environment
- Feature 2 - Different characters and optional conversations that change how you can interact with the environment
- Feature 3 - Multiple story routes with different endings

## Challenges
- How to create a functional story pathway with a start, end, and points where storylines intersect.
- How to create an inventory that holds intractable objects (door is locked. if inventory holds key, and player interacts with object, proceed to open unlocked door story path)
- How to make pleasing menu visuals and how to intake player input effectively
- How to store dialogue information to permit different interactions with objects (if dialogue was enacted with this character, open different option)
- How to update player location correctly and in relation to surrounding rooms 

## Outcomes
Ideal Outcome: 
- A fully functional game that maintains a believable and entertaining story pathway with three possible endings. Allows for player to talk to two other characters, interact with objects, obtain information about those objects, and use them in conjunction with the environment.
Minimal Viable Outcome: 
- A fully functional game that has one ending, allowing the player to pick up 
objects and use them to progress in the story.

## Milestones

3. Create and finish object list

3.Create one functional player-character interaction with dialogue
- Week N (Final)
1. Finish implementing script for main two story pathways
2. Implement all objects into the environment
3. Clean up any bugs
